
# 🖥️ Products Management Frontend (Angular)

Este proyecto es un **frontend en Angular** para consumir la API de Products Management.

---

## 🚀 Tecnologías
- Node.js 22.x (entorno de ejecución)
- Angular 17+ (standalone con Vite)
- Bootstrap 5 (estilos)
- Angular Router
- HttpClient (consumo de API)
- Formularios reactivos y validaciones

---

## 📂 Estructura de carpetas
src/app/
│── products/
│ ├── product.model.ts # Modelo de datos
│ ├── product.service.ts # Servicio HTTP
│ ├── product-list.ts/html # Listado con paginación
│ ├── product-form.ts/html # Formulario de creación/edición
│── app.routes.ts # Rutas principales
│── app.ts # Componente raíz
│── app.config.ts # Configuración inicial
